🏠 سامانه هوشمند املاک پارسیا

Parsia Real Estate Management System
📌 معرفی پروژه

سامانه املاک پارسیا یک وب‌سایت تخصصی در زمینه خرید، فروش، رهن و اجاره املاک است که با هدف ایجاد بستری ساده، مدرن و کاربردی برای جستجو و معرفی املاک طراحی و توسعه داده می‌شود.

این پروژه با تمرکز بر اصول طراحی رابط کاربری (UI) و تجربه کاربری (UX)، تلاش می‌کند محیطی زیبا و کاربرپسند برای مشاهده مشخصات املاک، جستجوی هوشمند و ارتباط با مشاوران املاک فراهم کند.

🎯 اهداف پروژه

- طراحی یک وب‌سایت حرفه‌ای برای املاک پارسیا
- جستجو و دسته‌بندی املاک
- نمایش اطلاعات و مشخصات هر ملک
- طراحی رابط کاربری فارسی و راست‌چین
- ایجاد تجربه کاربری ساده و روان
- آشنایی با HTML، CSS و JavaScript
- توسعه و مدیریت پروژه با GitHub

🛠️ تکنولوژی‌ها

- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages
